# QuickEd Solutions — Course Design

A React + Vite course showcase styled to match the QuickEd Solutions website identity.

## Updates in this version
- Updated the header and hero section to follow the supplied QuickEd website screenshot.
- Added the supplied QuickEd logo in the header, hero visual and footer.
- Expanded the course collection from 5 to 7: Java Full Stack, Python Full Stack, Generative AI, Cybersecurity, Software Testing, Soft Skills and Digital Marketing.
- Updated the course count, selectors and cards to use all 7 courses.
- Aligned the visual palette to near-black, forest-black and crimson red.
- Added responsive navigation/card layouts, subtle hover/reveal/orbit animations and reduced-motion support.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The logo is stored at `public/quicked-logo.png` and is loaded from the public root.
